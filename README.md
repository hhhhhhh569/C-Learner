# C-Learner 智能编程助手 🚀

**C-Learner** 是一款专为大一新生打造的 C 语言学习垂直领域 AI 智能体（Agent）。基于 WorkBuddy 平台与 Hy3 大模型构建，旨在解决初学者在编程入门阶段“报错看不懂”、“环境配不通”、“过度依赖 AI 直接要代码”的三大痛点。

## 💡 核心痛点与解决方案
1. **报错翻译机**：把冷冰冰的编译器报错（如 `expected ';'`）翻译成大白话，精准指出错误行号，但不直接给答案，引导学生自己改。
2. **环境急救包**：针对 Dev-C++ / 小熊猫 C++ 等新手常用编辑器，提供控制台闪退、中文乱码等常见环境问题的分步排查指南。
3. **代码审查与注释**：审查学生的代码规范（如拼音命名、缩进），并逐行添加通俗易懂的注释。

## 🛠 技术架构与创新点
- **底层模型**：选用 Hy3 模型（平衡中文理解与代码能力）。
- **Prompt Engineering（提示词工程）**：设计了“苏格拉底式”启发人设，并在系统提示词中设定**“禁止直接给完整代码”**的强约束。
- **长期记忆（Memory）机制**：在测试中通过对话反馈，让智能体自动将“只点行号不给代码”写入长期记忆（`.workbuddy/memory/MEMORY.md`），实现越用越懂学生的个性化教学。
